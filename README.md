# 💻 Meu Primeiro Projeto Web: Favoritos

Este projeto marca o início da minha jornada na programação e minha transição de carreira. O objetivo foi criar uma página simples que reúne meus sites mais acessados, aplicando conceitos fundamentais de desenvolvimento web.

## 📝 O que aprendi e realizei:

* **Estruturação HTML:** Inserção e redimensionamento de imagens e criação de links funcionais.
* **Organização de Diretórios:** Criação de uma estrutura de pastas independente para o projeto.
* **Versionamento Profissional:** Uso do terminal para executar o fluxo completo de Git (`git init`, `git add`, `git commit` e `git push`).

## 🛠️ Ferramentas Utilizadas:

* **Visual Studio Code:** Editor de código principal.
* **Git:** Versionamento de código.
* **GitHub:** Hospedagem e publicação do projeto.
