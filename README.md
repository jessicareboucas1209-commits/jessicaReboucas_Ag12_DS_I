💻 Meu Primeiro Projeto
Web: Favoritos
 
Este projeto marca o início da minha jornada na programação
e transição de carreira. 
O objetivo foi criar uma página simples que reúne meus sites
mais acessados, aplicando conceitos fundamentais de desenvolvimento.

realizei:

criação de links funcionais.

pastas independente para o projeto.
 
Versionamento Profissional: Uso do terminal para executar o
fluxo completo de Git (init, add, commit e push).

Utilizadas:
 
Visual Studio Code: Editor de código principal.
 
Git: Versionamento de código.
 
GitHub: Hospedagem e publicação do projeto.
